The header, search and portrait screenshot also have JPEG copies. PNG is
recommended to avoid format conversion when downloading/uploading on iPhone.
All exported PNGs use opaque RGB (PNG color type 2), without an alpha channel.

The portrait screenshot preserves the supplied image's complete UI, text,
aspect ratio and status bar. The supplied attachment is a compressed 591 × 1280
JPEG; the larger export resamples that image and does not add native detail.
Replace it with an original-resolution PNG capture when available for sharper
results. The marketing artwork embeds that same real capture; it does not
invent a new app screen or an iPhone hardware frame.

The `Koe-Universal-DE-5244x2950.png` file is an older German creative asset,
retained for reference. Use the current English files above for this submission.

These images must be uploaded to the relevant App Store Connect fields manually.
Updating files in GitHub does not replace assets already uploaded to Apple.
The app icon installed on iPhone comes from the app build's asset catalog.
